INSPIRE V1.0 Evaluation Materials

This repository provides available study materials for the evaluation of INSPIRE V1.0 in pediatric rare-disease diagnosis, associated with JMIR Medical Informatics manuscript #108320.

Scope

Materials will be added as they are checked and prepared for public release. These may include case-tier inputs, retained first-run diagnosis lists, diagnostic rankings and scoring records, available user-prompt records, and analysis code.

Documentation Limitations

Each case-tier condition was run three times per system during the original evaluation. Only the first-run output was retained and analyzed. Outputs from the second and third runs are unavailable.

The INSPIRE platform has subsequently changed. Materials in this repository relate to the historical study and do not establish reproducibility using the current platform.
